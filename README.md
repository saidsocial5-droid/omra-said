# 🕋 عمرة سعيد — Umrah Companion

تطبيق ويب تقدّمي (PWA) باللغة العربية يرافق المعتمر طيلة رحلته (15 يوماً افتراضياً)، ويعمل **بدون إنترنت** بعد أول فتح، ويُثبَّت على الهاتف كتطبيق عادي.

## ✨ المميزات
- 🧭 **المساعد الذكي «ماذا أفعل الآن؟»**: يقترح عليك ما تفعله حسب يوم الرحلة، والوقت، والصلاة القادمة.
- 🕌 **مواقيت الصلاة** لمكة والمدينة (طريقة أم القرى) مع العدّ التنازلي، وتحديد المدينة تلقائياً بالموقع.
- 🕋 **صفة العمرة خطوة بخطوة**: الإحرام، التلبية، الطواف، ركعتا الطواف، السعي، الحلق/التقصير — مع تتبّع التقدم.
- 🔄 **عدّاد الطواف والسعي** مع اهتزاز عند كل شوط وتنبيه عند الإتمام.
- 📿 **الأذكار والأدعية** بعدّادات: السفر، المسجد، الصباح والمساء، بعد الصلاة، أدعية قرآنية ونبوية، زيارة المدينة، وقسم **أدعيتي الخاصة** لمن أوصاك بالدعاء.
- ✈️ **السفر من أزرو**: البحث عن رحلات الطيران (Google Flights، Skyscanner، Kayak) من فاس أو الدار البيضاء أو الرباط أو مراكش، ومسار الحافلات والطاكسي من أزرو إلى المطار مع حساب وقت الخروج، والبحث عن الفنادق قرب الحرمين (Booking، Google Hotels، Agoda) بتواريخ مضبوطة تلقائياً، والتنقل داخل السعودية (قطار الحرمين، سابتكو).
- 🗺️ **المزارات** في مكة والمدينة مع روابط الخرائط وتتبّع ما زرته.
- 📍 **الخرائط** وزر «أرجعني إلى الفندق».
- 📅 **برنامج 15 يوماً** قابل للتعديل (مكة أولاً أو المدينة أولاً، وعدد الأيام).
- ⭐ **نصائح ذهبية**، 🎒 **قائمة التجهيز**، 📿 **سبحة إلكترونية**، 📝 **مذكرات الرحلة**.
- 🔒 كل البيانات تُحفظ على جهازك فقط.
- 🔄 **تحديث تلقائي**: كل تعديل يُرفع إلى المستودع يُنشر تلقائياً (GitHub Actions)، ويتحدث التطبيق على الهاتف وحده عند الاتصال بالإنترنت دون فقدان بياناتك.

## 📲 التحميل والتثبيت
### 🤖 تطبيق أندرويد (APK)
**[⬇️ تحميل omra-said.apk](https://github.com/saidsocial5-droid/omra-said/releases/latest/download/omra-said.apk)** — افتح الملف على الهاتف واسمح بالتثبيت من مصادر غير معروفة. التطبيق يتحدث محتواه تلقائياً من الإنترنت ويعمل بدونه.

### الطريقة 1 — من الرابط (الأسهل)
افتح رابط GitHub Pages الخاص بالمستودع على هاتفك، ثم:
- **أندرويد (Chrome)**: القائمة ⋮ ← «تثبيت التطبيق».
- **آيفون (Safari)**: زر المشاركة ← «إضافة إلى الشاشة الرئيسية».

### الطريقة 2 — تحميل الملفات
اضغط **Code ← Download ZIP**، فك الضغط وافتح `index.html` في المتصفح.

## 🛠️ التقنية
HTML + CSS + JavaScript خالص، بدون أي مكتبات أو خادم. ملف واحد `index.html` + `sw.js` للعمل دون اتصال + `manifest.json`.

## ⚠️ تنبيه
المحتوى للتعليم العام وفق ما عليه جمهور أهل العلم؛ في المسائل الخاصة يُرجع إلى أهل العلم الموثوقين. مواقيت الصلاة حساب تقريبي — اعتمد على أذان الحرمين.
